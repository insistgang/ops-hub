# Ops-Hub 产品与架构规格说明书 (PRD v2.0)

> **定位**：个人数字化运营工作总台（公开 Showcase + 日常控制塔，零构建单页 + 纯标准库 CLI）
> **在线站点**：`https://ops.insistgang.top/`（阿里云独立 release）· `https://insistgang.github.io/ops-hub/`（GitHub Pages 镜像）

---

## 1. 核心设计原则

1. **🚫 零 Mock 真实数据铁律**：页面与 CLI 展示的全部指标均来自真实硬件探针、Career-Copilot 求职台账、本地 Git 仓库、Obsidian 知识库与真实账本/日程接口；离线或解析失败时诚实降级留白，绝不编造数据。
2. **⚡ 零构建静态直出**：根目录 `index.html` 直接运行，支持 `file:///` 离线双击查看与静态托管秒级上线；VitaFlow、体重、财务三个子系统在开发期通过零依赖 `node build.mjs` 合成单实例原生工作区片段，线上零运行时打包。
3. **🔐 隐私分级与单向投影**：
   - 本地真源（`data/*.json`、`data/private/`、口令配置）严格 `git-ignore`。
   - 公开产物（`data/public/`）经 `scripts/sanitize_public.py` 白名单裁剪、人物代号化、私网 IP 掩码与残余敏感词阻断校验后方可提交发布。
   - Career-Copilot 与 `~/Documents/knowledge` 均为单向只读上游，Ops-Hub 绝不回写上游真源。
4. **🛠️ 双端自动对齐发布**：macOS 原生 `launchd` 每日 09:00 / 21:00 执行 `scripts/sync_all.py`，依次完成「探针采集 + GitHub 推送 → 阿里云独立目录发布与 MD5 校验 → 日记消费入账 → 线上核验」，消除双站分叉与备份堆积。

## 2. 八大工作区信息架构

### 顶栏与全局 Hero 指标
- **顶栏状态带**：北京时间秒级时钟、快照时效胶囊（超 13 小时自动标黄预警「需同步」）、Win 4070S / Jetson 快照延迟胶囊、四套视觉风格切换（经典/纸感/森林/海蓝）与明暗主题切换。
- **三大全局指标卡**：六级（CET-6）动态考期倒计时、求职投递大盘统计、三端异构算力在线节点概览。

### 工作区模块
1. **🌅 今日 (`#tab-today`)**：浏览器本地最多 3 件今日重点 + 昨日未完成显式带入；只读同步知识库「今日必做 + 当前 WIP + 硬节点雷达」；右侧聚合 VitaFlow 今日待办/四账户、最新体重及内存态财务摘要。
2. **🎯 求职投递看板 (`#tab-career`)**：单向投影 Career-Copilot 台账，支持「全部 / 面试中 / 笔试中 / 已录用 / 初筛 / 已投递」六档过滤，活跃推进阶段自动置顶。
3. **🚀 多线项目雷达 (`#tab-projects`)**：自动抓取本地核心工程最新 Git 提交与超期未提交提示、考期冲刺卡片，以及知识库项目台账全量事实投影。
4. **🧠 个人记忆与秩序 (`#tab-memory`)**：每日四勾打卡（起了/动了/写了/关了）、图书馆/实验室/宿舍场景契约、认知防散基线。
5. **⚖️ 体重管理 (`#tab-weight`)**：原生挂载通用体重追踪器，支持多使用者、目标对比、SVG 趋势折线与本机小组；公开投影仅合并本人缺失基准记录，绝不覆盖本机已有数据。
6. **💰 财务管理 (`#tab-finance`)**：上方展示知识库月度财务复盘只读摘要；下方原生挂载四区财务工作台（总览/资产/逐笔/复盘），自动鉴权读取远端账本并仅驻留页面内存。
7. **📅 日程与精力 (`#tab-vitaflow`)**：原生挂载 VitaFlow 四账户精力管家（日历待办、番茄钟、状态趋势、创作与学习空间），附公开只读快照、日记待办按需导入与最近 7 天日记精力参考条形图。
8. **🖥️ 设备分工与算力总台 (`#tab-compute`)**：与 CLI 同源的关键词智能分流决策器、Mac M5 / Win 4070S / Jetson 专属任务与红线矩阵、多端协同流转表、硬件状态卡片及快捷 SSH 复制。

## 3. CLI 运维套件 (`ops`)

| 命令 | 职责说明 |
| :--- | :--- |
| `ops status` | 终端彩色输出三端拓扑、求职置顶进展、项目与考期、知识库必做/硬节点、体重与四勾 |
| `ops dispatch [query]` | 打印三端分工矩阵，或按关键词路由最优执行设备并给出 SSH 登录串 |
| `ops sync [--push] [--all]` | 执行探针与知识库采集；`--push` 提交推送 GitHub；`--all` 串联阿里云与账本全链路 |
| `ops career <list\|add\|update>` | 查看求职投影清单（上游缺失时支持本地回退维护） |
| `ops check <项> [--toggle]` | 快速打卡今日四勾，跨天自动归档至 `history` |
| `ops weight [kg]` / `ops memory` | 记录或查看个人体重趋势；终端打印场景契约与防散原则 |
| `ops publish` / `ops finance` | 独立发布阿里云站点并滚动清理旧版；同步日记实付消费至线上账本 |
| `ops quota` | 读取 `~/.cache/ai-quota-monitor/last-good.json` 换算剩余额度并给出早停建议 |
| `ops serve` / `ops schedule` | 启动 `127.0.0.1` 静态预览；安装/巡检/卸载 `launchd` 早晚定时任务 |
