# Ops-Hub 日常衔接与记录可靠性实施计划

> 执行方式：Coordinator 负责今日首页与验收；一个原生叶子 Worker 负责四勾。原本地阶段按小步测试实施，不提交或发布；2026-11-07 11:40 本人已另行授权把已验证成果提交并更新原网站，发布状态以 ROADMAP 为准。

**目标**：每天打开时能衔接昨日未完成事项；浏览器保存失败、跨日或多个标签页操作时，界面如实反映已保存的记录。

**技术与边界**：继续使用现有 HTML、CSS、原生 JavaScript 和 localStorage，无新增依赖。保持 `ops_focus_YYYY-MM-DD`（`{text, done}` 数组）和 `ops_checks_YYYY-MM-DD`（布尔值对象）兼容。日界统一使用 `calendarDay()` 的北京时间。所有样例只用于隔离测试，不写入个人记录。既有未提交改动保留。

## 设计决定

- 昨日未完成重点逐项显示「安排到今天」，需要点击后才加入；不改写昨日，不自动继承。今日最多三件，已有同文事项不重复加入；完成数单独展示。
- 不加入历史查询系统、自动排程或跨设备服务。本轮使用已有按日保存的记录。
- 保存先成功写入再更新列表；失败时保留输入、原列表与原始存储，并在页面提示。损坏的存储拒绝覆盖。
- 操作前重读，发现其他标签页修改则刷新并提示重试；不让旧索引修改另一条记录。
- 午夜由现有时钟发出 `ops:day-changed`，今日首页随之重读。页面重新可见和 storage 事件也重读对应记录。
